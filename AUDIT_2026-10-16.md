# ATLAS STUDIO Audit — 2026-10-16

## Scope

This audit covered the current repository documentation, the architecture diagram embedded in the parent master specification, the skill-pack documentation, the complete Git history, the Rust workspace, and a real first-run production through Blender, Kokoro, and FFmpeg.

The repository contained one commit at audit start:

`d78faf6 feat: ATLAS STUDIO Milestone 1 complete`

## Material Findings and Corrections

| Area | Baseline finding | Correction | Verification |
|---|---|---|---|
| Production command | Wrote literal mock frame, audio, and MP4 files while reporting completion | Replaced with real Blender rendering, Kokoro synthesis, FFmpeg assembly, captions, thumbnail, metadata, and output validation | 30-second first-run MP4 produced from 900 rendered frames |
| Blender | Generated script was incompatible with Blender 5.1 and could report success after a Python traceback | Updated the generated scene and render code for Blender 5.1 and reject tracebacks even when Blender exits with code zero | Three 300-frame shots rendered at 1920x1080 and visually inspected |
| Kokoro | Invoked the wrong executable and unsupported flags | Integrated the installed `kokoro-tts` CLI and local model/voice files | Narration generated and assembled into the final video |
| FFmpeg | Invalid filter labels and fade expressions could break assembly | Rebuilt sequence, audio, concat, encoding, and validation paths | H.264 video and AAC audio validated with FFprobe |
| Agent bus | Store handling and request API did not support the intended durable path cleanly | Shared the store safely and introduced a typed review request | Workspace tests and strict Clippy pass |
| CLI state | Could mark a project ready after placeholder output | Readiness now requires verified frames, duration, output size, captions, metadata, disclosures, and credits | First-run project reached `READY_TO_PUBLISH` only after checks passed |
| Cached iteration | Every correction required a complete rerender | Added `--reuse-rendered` with frame-count verification | Final package rebuilt from a validated render cache |
| Documentation | Claimed mock output was a completed production system and that credentials were not tracked | Updated status, commands, milestone state, and security disclosure | Documentation now matches the tested local state |
