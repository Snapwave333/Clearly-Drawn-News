# Authored Blender/Unreal whiteboard render

## Pipeline
1. **GEOMETRY** — source SVG / layers from VectorCraft, written with editable paths
2. **DIRECT** — storyboard and motion director specify causes for animation and exact frame budgets
3. **BLENDER** — generate deterministically from scene JSON; use Grease Pencil or curves depending on installed version
4. **UNREAL** — select ONLY for educational spatial visualization not possible or clear in 2D
5. **OVERLAY** — EffectCraft original motion typography, diagrams and labels
6. **CHECK** — render draft, sample frames, text legibility and flash/motion checks
7. **FINAL** — render frame sequences, export manifest and freeze render settings

## Rules
Never use flat slideshow transitions as substitute for animation; limit each scene to one main visual concept at a time.

## Exit evidence
A completed workflow emits immutable artifact hashes, review gate statuses, agent/event trace IDs, and clear failure records. Do not substitute a successful LLM response for a verified native asset, fetched metric or upload confirmation.
